# Full-Stack Data Science + Generative AI

Follow numbered modules in order. Run examples, solve exercises, add tests, and document results. Install dependencies with `python -m pip install -r requirements.txt`. Run checks with `python -m unittest discover -s tests -v`.

## Curriculum
- [Python](01-Python/README.md): syntax, types, control flow, functions, collections, files, exceptions, OOP, modules, generators, decorators, typing, tests.
- [SQL](02-SQL/README.md): SELECT, joins, aggregation, subqueries, CTEs, windows, schema design, indexes, transactions.
- [NumPy and Pandas](03-NumPy-Pandas/README.md): arrays, vectorization, cleaning, missing values, joins, groupby, time series.
- [Statistics](04-Statistics/README.md): descriptive statistics, probability, distributions, sampling, confidence intervals, hypothesis tests, regression.
- [Visualization](05-Data-Visualization/README.md): Matplotlib, Seaborn, chart choice, design, storytelling, dashboards.
- [Exploratory Data Analysis](06-EDA/README.md): data quality, univariate and bivariate analysis, leakage, feature hypotheses.
- [Machine Learning](07-Machine-Learning/README.md): splits, baselines, preprocessing, regression, classification, clustering, metrics, tuning, pipelines.
- [Deep Learning](08-Deep-Learning/README.md): tensors, neural networks, backpropagation, optimizers, regularization, CNNs, transfer learning.
- [NLP and Generative AI](09-NLP-and-Generative-AI/README.md): text, embeddings, transformers, prompting, structured output, tools, RAG, evaluation, safety.
- [FastAPI](10-FastAPI/README.md): REST, validation, inference endpoints, errors, tests, versioning.
- [Streamlit](11-Streamlit-Dashboards/README.md): widgets, charts, state, uploads, caching, model demos.
- [Deployment and Docker](12-Deployment-and-Docker/README.md): environments, Docker, configuration, logging, CI, monitoring.
- [End-to-End Projects](13-End-to-End-Projects/README.md): problem framing, baselines, pipelines, APIs, dashboards, tests, docs.
- [Exercises](14-Exercises/README.md): Python, SQL, pandas, statistics, ML, NLP, GenAI, APIs.
- [Interview Preparation](15-Interview-Preparation/README.md): Python, SQL, statistics, ML, DL, NLP, GenAI, system design.
