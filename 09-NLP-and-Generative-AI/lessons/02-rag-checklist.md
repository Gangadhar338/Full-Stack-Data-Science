# RAG checklist

1. Use documents you are allowed to process. 2. Chunk text and preserve source metadata. 3. Retrieve relevant passages. 4. Answer from evidence and admit when evidence is insufficient. 5. Return real citations, never invented ones. 6. Evaluate retrieval, correctness, groundedness, latency and cost. 7. Treat retrieved text as untrusted; test prompt injection and protect sensitive data.
