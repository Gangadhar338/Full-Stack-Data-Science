# Python Functions

## Learning objectives
- Define and call functions.
- Use parameters and return values.
- Understand default arguments and scope.

## Example
```python
def calculate_total(price, quantity=1):
    return price * quantity

print(calculate_total(100, 3))
```

## Practice
1. Write a function that adds two numbers.
2. Write a function that returns the largest of three numbers.
3. Write a function that calculates a factorial.
