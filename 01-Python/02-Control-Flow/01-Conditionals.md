# Python Conditionals

## Learning objectives
- Use if, elif, and else.
- Combine conditions with and, or, and not.
- Understand indentation.

## Example
```python
score = 82
if score >= 90:
    grade = "A"
elif score >= 75:
    grade = "B"
else:
    grade = "C or below"
print(grade)
```

## Practice
1. Classify a number as positive, negative, or zero.
2. Check whether a number is even or odd.
3. Convert a score into a grade.
