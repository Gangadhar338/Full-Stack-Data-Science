# Python Loops

## Learning objectives
- Iterate with for and range.
- Use while loops.
- Understand break and continue.

## Example
```python
for number in range(1, 6):
    print(number)

count = 3
while count > 0:
    print(count)
    count -= 1
```

## Practice
1. Print numbers from 1 to 100.
2. Calculate the sum from 1 to n.
3. Print a multiplication table.
