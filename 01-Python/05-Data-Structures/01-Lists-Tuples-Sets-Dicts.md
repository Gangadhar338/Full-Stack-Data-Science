# Python Data Structures

## Lists
Ordered, mutable collections: `values = [10, 20, 30]`.

## Tuples
Ordered, immutable collections: `point = (3, 4)`.

## Sets
Collections of unique values: `unique = {1, 2, 2, 3}`.

## Dictionaries
Key-value mappings: `student = {"name": "Asha", "age": 20}`.

## Example
```python
scores = [70, 80, 90]
scores.append(95)
student = {"name": "Asha", "scores": scores}
print(student["name"])
print(sum(scores) / len(scores))
```
