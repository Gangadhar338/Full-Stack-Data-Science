# Virtual Environments and Packages

Virtual environments isolate dependencies for a project. Create one with `python -m venv .venv`. Activate it in Windows CMD with `.venv\\Scripts\\activate.bat`. Install packages using `python -m pip install package-name`. Record dependencies with `python -m pip freeze > requirements.txt`.

## Practice
1. Create and activate a virtual environment.
2. Check the pip version.
3. Explain why projects should isolate dependencies.
